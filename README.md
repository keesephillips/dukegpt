# DukeGPT
## AIPI 590 Large Language Models
## Developer: Keese Phillips

## About:
The purpose of this project is to create a chatbot for perspective and current students of the university. This chatbot should be able to answer commonly asked questions about student life, admissions, and academics. The chatbot is designed using agentic search through LangChain and the model chosen is the deepseek-ai/DeepSeek-R1-Distill-Llama-8B. 

## Project Structure
> - model.py: contains the LangChain Agent and all tools 
> - app.py: main script/notebook to run streamlit user interface
> - assets: directory for images used in frontend 
> - data: directory for the knowledge base tools  
> - notebooks: directory to store the webscrapping notebook used
> - .gitignore: git ignore file
